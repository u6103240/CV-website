Project Analysis

User Profile: User Persona

Name:Alex Johnson  
Age:24 years  
Occupation:Software Engineering Student / Junior Developer  

Background:

Alex is a young person who is interested in software development and technology. He is looking for new job opportunities and wants to show his skills, education, and experience to companies. He needs a simple and professional website where recruiters can find all the important information about him.

Alex wants to present his skills and professional experience, as well as showing personal projects and having a good first impression. He needs a website that is easy to navigate and understand. 
He also needs to have a website that has simple navigation between the different sections and visible and accessible contact information


Information Architecture:

The website is designed as a single-page CV. All the information is presented on one page, divided into different sections. This structure makes the website simple to use because visitors do not need to open different pages to find information.

At the top of the page, there is a fixed navigation bar with links to the main sections: About Me, Education, Experience, Portfolio, Skills, and Contact. The navigation bar stays visible while scrolling, allowing visitors to move quickly between sections.

The first section is the presentation area. It shows my name, my professional title, and a personal image. Its purpose is to introduce me and give visitors a clear idea of who I am.

The About Me section contains a short introduction about my interests in technology, programming, and software development. After that, the Experience section presents my previous professional roles and the main tasks I performed in each position.

The Education section shows my academic background, including my degrees and the main subjects I studied. The Portfolio section presents three projects: a Subscription Management System, a Project Management Platform, and a Personal Portfolio Website. Each project includes a title, a description, and an image.

The Skills section groups my technical knowledge into four categories: Programming, Web Development, Database Management, and Tools and Technologies. This organization makes the information easier to read.

Finally, the Contact section displays my email address, telephone number, and address. The footer closes the page with a copyright notice.


Visual Design

The main goal of the visual design is to create a simple and professional CV website that atracts the user with the outstanding colors (not the usual white color). I chose a dark theme because it gives the page a clean appearance and helps the content stand out.

The main background color is a very dark gray. Most content sections use a slightly lighter dark gray to create a small difference between the background and the content. The presentation section uses another dark gray so the introduction stands out from the rest of the page.

I chose a warm orange color, for the main text and important elements. This color creates contrast with the dark background and gives the website a recognizable style. White is used for headings and navigation links because it is easy to read. The footer uses a softer beige color to maintain the same visual style without being too bright.

The website uses Arial as its main font. I chose this font because it is simple, familiar, and easy to read on different screens. Headings have larger font sizes to create a clear visual hierarchy. The main title is larger than the section headings, helping visitors understand the structure of the page.

I used Flexbox for the presentation and contact sections because it allows elements to be aligned and spaced easily, grid is used for the portfolio and skills sections. On desktop screens, the portfolio shows three projects in columns, while the skills section uses four columns.

The design also includes a fixed navigation bar with a transparent dark background. This keeps the navigation available while visitors scroll through the page. Project images use rounded corners to create a more consistent appearance.

Finally, I added CSS media queries to adapt the layout to smaller screens. On mobile phones, the presentation changes to a vertical layout, the portfolio displays one project per row, and the skills section uses two columns, making the website easier to use on different devices.
